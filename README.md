# 법령 검색 및 Q&A 챗봇 모델

방대한 법령 정보를 일반인들이 쉽게 찾을 수 있도록 하는 RAG 시스템입니다.
참고한 조/항을 함께 답변에 포함하여 명확한 답변을 제공합니다.   
**각 법령마다 RAG성능을 올리기위한 접근방식이 다르게 적용되었습니다.**

## 2. 🗂️ 폴더 구조

```text
├── A-TEAM/               
│   └── README.md          
├── B-TEAM/               
│   └── README.md          
├── C-TEAM/               
│   └── README.md          
└── README.md              
```
team A,B,C 각각 하나의 법령을 맡아 개발하였습니다.   
각 팀의 폴더 하위에 README.md이 있으며 개발 상세내역이 포함되어 있습니다.  
**tema A - 노동법**  
**tema B - 사회복지법**  
**tema C - 형사법**  

## 3. 📊 공통 데이터 수집 및 전처리

### - 수집

**출처**: [국가법령정보센터](https://www.law.go.kr)

`BeautifulSoup` 및 `Selenium`을 활용한 동적 웹 크롤링으로 수집하였습니다.  
불필요한 목차, 하단 footer 등등 데이터 제거 전처리를 진행하였습니다.

### - Database

법령의 계층 구조를 보존하기 위해 각 법령을 **조(Article)** 및 **항(Clause)** 단위로 나누어 벡터화하여 저장하였습니다.
